# Casa da Química

Loja virtual de material de laboratório, feita em Angular, com temática Breaking Bad.

## Funcionalidades

- Vitrine de produtos com destaque e preço promocional
- Busca de produtos por nome ou descrição
- Página de detalhe do produto
- Cesta de compras salva no `localStorage`
- Login, cadastro e pedido

## Como rodar

```bash
npm install
npm start
```

Depois abra `http://localhost:4200/`.

## Build

```bash
npm run build
```

Os arquivos gerados ficam em `dist/`.
